# 🏠 flat-bot — бот проти повторних посилань на квартири

Телеграм-бот для групи, де ви з хлопцем скидаєте варіанти квартир.

**Що вміє:**
- ловить усі посилання в групі й запам'ятовує їх (навіть якщо повторка має інші utm-мітки, `www.`, мобільну версію сайту тощо);
- нове посилання тихо позначає реакцією 👌;
- якщо посилання **вже кидали** — відповідає попередженням: хто й коли кидав, з посиланням на оригінал, і кнопками **«🗑 Видалити повторку» / «✋ Залишити»**;
- `/check` — перевіряє, чи всі збережені оголошення ще актуальні (розуміє OLX, DIM.RIA, rieltor.ua та типові сторінки «оголошення видалено»);
- щодня о 10:00 сам перевіряє актуальність і пише в групу, **лише якщо** щось стало неактуальним;
- `/list` — список усіх збережених посилань зі статусами ✅/❌.

## Налаштування (один раз, ~5 хвилин)

### 1. Створи бота
1. Напиши [@BotFather](https://t.me/BotFather) в Телеграмі → `/newbot`.
2. Придумай ім'я та юзернейм (має закінчуватись на `bot`).
3. Скопіюй токен, який він видасть.

### 2. Встав токен
1. Скопіюй файл `.env.example` → перейменуй копію на `.env`.
2. Відкрий `.env` блокнотом і встав свій токен замість прикладу.

### 3. Додай бота в групу
1. Додай бота в вашу групу.
2. Зроби його **адміністратором** з правом **«Видалення повідомлень»** — це потрібно, щоб він бачив усі повідомлення і міг видаляти повторки.

### 4. Запусти
Подвійний клік на `start.bat` — він сам створить середовище, встановить залежності й запустить бота. Вікно має залишатися відкритим, поки бот працює.

Або вручну:

```bash
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
.venv\Scripts\python bot.py
```

## Як користуватись

Просто кидайте посилання в групу як звикли. Бот сам усе робить.

| Команда | Що робить |
|---|---|
| `/check` | перевірити актуальність усіх збережених оголошень |
| `/list` | показати всі збережені посилання |

## Нюанси

- Бот працює, поки запущений на комп'ютері. Якщо хочеться 24/7 — можна закинути на безкоштовний хостинг (наприклад, [PythonAnywhere](https://www.pythonanywhere.com/) або Railway) — файли ті самі.
- База зберігається у файлі `links.db` поруч з ботом. Видалиш його — бот забуде всі посилання.
- Перевірка актуальності не стовідсоткова: деякі сайти (особливо LUN) закриваються від ботів. Якщо бот не зміг перевірити сторінку, він **не** позначає її неактуальною, а чесно пише «не зміг перевірити».
